# Лабораторная работа 4 — вариант 10

За основу взяты исходники ЛР2. Сохранены их структура, имена переменных, функции проверки чисел и основной цикл обработки. Изменён способ обмена: вместо канала используется отображаемый файл.

Ребёнок читает числа из файла, проверяет их на простоту и передаёт составные числа родителю через отображаемый файл. На первом простом или отрицательном числе обработка заканчивается. Числа 0 и 1 пропускаются.

## Сборка и запуск

Из папки проекта:

```bash
cmake -S . -B build
cmake --build build
./build/parent ./build/child
```

После `Input file:` ввести `data/stop_prime.txt`. Результат — 4 и 9, остановка на 7.

## Как работает

1. Родитель открывает входной файл и создаёт временный файл для ответа.
2. После fork ребёнок подключает вход к stdin, файл ответа к stdout и запускает child через execl — так же, как в ЛР2, только вместо канала используется файл.
3. child записывает строки с составными числами через mmap с MAP_SHARED.
4. После обработки child снимает отображение и обрезает файл до длины ответа через ftruncate.
5. Родитель ждёт ребёнка через waitpid, узнаёт размер ответа через fstat, читает его через mmap и выводит в терминал.

Файл содержит только текст чисел. Дополнительных структур и флагов нет. При пустом ответе родитель ничего не отображает и не выводит. При ошибке ребёнка результат не выводится, код завершения равен 1.

## Файлы

`parent.c` — исходный родитель из ЛР2 с заменой канала на файл; `child.c` — исходный ребёнок с записью через mmap вместо printf. В CMake изменено только имя проекта. `data/` содержит входные примеры. Команды для восьми скриншотов находятся в `Запуск.txt`, краткий разбор — в `Объяснение_ЛР4.md`.

Вход должен быть обычным файлом и не меняться во время работы. Память для ответа берётся по размеру входа с запасом в два байта: для последнего перевода строки и завершающего нуля snprintf. Имя временного файла сразу удаляется через unlink; сам файл существует до закрытия дескрипторов и отображений.
